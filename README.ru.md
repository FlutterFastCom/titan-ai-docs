# titan-ai-docs

Инструкции для ИИ-ассистента (Claude, Codex или любого другого), который помогает пользователю работать с Titan.
Файлы написаны для ИИ, а не для людей. English version: `README.md`.

- Веб-приложение Titan: https://app.titan.red
- MCP-сервер Titan (к нему подключается ИИ): https://backend-production-585b.up.railway.app/mcp
- С чего начать: `SETUP.ru.md`. Версии Titan, которым соответствуют эти документы: `VERSION`.
- Ассистент отвечает на языке пользователя (русском или английском) и называет кнопки так, как их показывает приложение.

Сгенерированные части обновляются автоматически после каждого проверенного релиза Titan. Свежий архив:
https://github.com/FlutterFastCom/titan-ai-docs/releases
