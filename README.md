# titan-ai-docs

Instructions for an AI assistant (Claude, Codex, or any other) that helps a user operate the Titan platform.
These files are written for the AI, not for people. Русская версия: `README.ru.md`.

- Titan web app: https://app.titan.red
- Titan MCP server (what the AI connects to): https://backend-production-585b.up.railway.app/mcp
- Start: `SETUP.md` (по-русски: `SETUP.ru.md`). Versions these docs match: `VERSION`.
- The assistant answers in the user's language (English or Russian) and names buttons as the user's app shows them.

Generated parts are refreshed automatically after each reviewed Titan release. Download the latest zip from
https://github.com/FlutterFastCom/titan-ai-docs/releases
